# BlockBreakTrust

BlockBreakTrust is a Minecraft plugin designed to restrict players from breaking blocks, allowing them to only break Cobwebs, Obsidian, and Stone. This plugin includes a permission command, `/Breaktrust`, which developers can use to grant players the ability to break any block.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to enable the plugin.

## Use

1. Players without the `blockbreaker.breaktrust` permission will only be able to break Cobwebs, Obsidian, and Stone.
2. To grant a player the ability to break any block, use the command `/Breaktrust` while holding the desired block.
